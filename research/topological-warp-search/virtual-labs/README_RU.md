## Стандарты доказательств

1. Одно полное действие `S[g,A,φ,...]` со всеми полями, масштабами и коэффициентами.
2. Согласованные уравнения Эйнштейна/Максвелла/скалярных и KK-секторов, сеточная сходимость и независимая реализация.
3. Обсервационные предсказания вычисляются **из того же действия**, без подстановки произвольных γ и c_T.
4. NEC/WEC/DEC для всех наблюдателей, QEI, backreaction, ghost/gradient stability, global null geodesics, causality.
5. Сравнение с реальным экспериментом вне обучающей выборки, uncertainty propagation, негативные контроли.
6. **Не повышать `UNKNOWN` в `PASS`, не выводить физический FTL из совпадения с Cassini или из допустимого параметрического диапазона.**
