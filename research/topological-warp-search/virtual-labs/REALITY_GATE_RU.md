# NX-01 Reality Gate · 25 октября 2026

**Ключевой результат:** 14/14 тестов воспроизводимого локального симулятора прошли. Физически реализуемый FTL НЕ обнаружен; предложен лабораторно измеряемый контроль Казимира. Это исследовательская ветка, НЕ production.

## Математический тест 4D GR

Контрольная **бесконечная плоская сдвиговая метрика** (не трубка Красникова, не готовый конечный пузырь):

`ds²=−dt²+(dx−v(y)dt)²+dy²+dz²`, `v(y)=A exp[−y²/(2L²)]`; сигнатура (−,+,+,+), geometrized units G=c=1.

Точный полный Einstein tensor `G_ab` независимо выведен через Christoffel/Ricci в SymPy, не только локально предположен. Для эйлерова наблюдателя `n=(1,v,0,0)`:

- `G(n,n)=−[v'(y)]²/4`, то есть `ρ_n=−c⁴[v']²/(32πG)` в SI.
- Для нулевого `k=n+e_z=(1,v,0,1)`: `G(k,k)=−[v']²/2`.
- WEC и NEC этой геометрии нарушены при `v'≠0`; это **контрпример для данного анзаца**, не no-go для всех метрик.

При `A=10^-6, L=1 м, y=1 м` модуль ρ_n≈4.4287662×10^29 Дж/м³.

## Проверяемая лаборатория Казимира

- Идеальная модель бесконечных пластин: `P=−π²ħc/(240 a⁴)`; при `a=100 нм`: **−13.0013 Па**.
- Энергия взаимодействия для идеальных пластин `U/A=−π²ħc/(720a³)`. При площади `1 см²`, `a=100 нм`: **−4.33375×10^-11 Дж**, плотность **−4.33375 Дж/м³**.
- Практичнее сфера–плоскость: идеальная PFA `F=−π³ħcR/(360 a³)`. При `R=100 мкм`, `a=100 нм` модуль **272.3 пН**. *Не готовое реальное предсказание*: обязательны Lifshitz/finite conductivity, thermal, roughness, electrostatic patches, gap calibration.
- Разрыв между Эйнштейновым **игрушечным** источником ρ_n и идеальным Казимиром при 100нм около **1.02×10^29** раз (разные пространственные конфигурации, не универсальный нижний предел FTL).
- Упрощённая оценка `G|U|/(c⁴ r)` при `r=1 см` порядка **3.58×10^-53**, и она не является рассчитанной гравитацией реального Casimir-прибора (не включены поддерживающие напряжения и пластины).

Создана тестовая выборка **12 расстояний × 60 синтетических измерений**, шум 3%+0.75пН, преднамеренная погрешность зазора +0.8нм; fit exponent **−3.0049**, 95% bootstrap ≈[−3.015,−2.997]. Это QA программы, не новая экспериментальная физика.

## Строгая последовательность для реального стенда

1. Согласовать лабораторию (AFM/микрокантилевер, вакуум, калибровка пьезозазора), реальные материалы, температурный диапазон, метрологию шероховатости.
2. Измерить F(V) на зазорах, контактные и патч-потенциалы; контрольные серии на больших расстояниях, рандомизация последовательности, термодрейф.
3. Зарегистрировать основную material-corrected модель Lifshitz **до** эксперимента, провести пилотный power analysis, сохранить сырые данные и полные неопределённости.
4. Только после этого сравнивать наблюдаемое с теоретическими формулами. **Измерение Casimir не доказывает FTL и не демонстрирует источник макроскопической экзотической энергии.**
